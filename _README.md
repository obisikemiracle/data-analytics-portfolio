# Deluxe Store Sales Analysis 

## Project Overview

This project analyzes Deluxe Store's sales data from 2014 to 2017 using Power BI. It explores sales performance, product profitability, loss-making products, and discount patterns to identify business insights and support data-driven decision-making.

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- DAX
- Microsoft PowerPoint

## Project Dashboards

- Sales Performance Dashboard: Analyzes sales trends and overall business performance.
- Profit Analysis Dashboard: Evaluates profitability across products, categories, sub-categories, and customer segments.
- Loss Analysis Dashboard: Identifies loss-making products and sub-categories.
- Discount Analysis Dashboard: Examines profit across discount levels and average discounts by product sub-category.

## Key Findings

- Total sales were approximately $2.30 million.
- Total profit was approximately $286,408.08.
- Overall profit margin was approximately 12.47%.
- Technology was the most profitable product category.
- The Consumer segment generated the highest profit.
- Some products and sub-categories recorded losses, highlighting opportunities to improve profitability.
- Profitability varied across discount levels, making discount strategy an area for further investigation.
