# ShopSmart Retail Analytics Project

## Project Overview

This project analyses retail data for ShopSmart Retail Ltd. using Microsoft Excel. The goal is to examine sales performance, customer behaviour, product performance, returns, and inventory to support business decision-making.

## Tools Used

- Microsoft Excel
- Excel formulas and lookup functions
- PivotTables and PivotCharts
- Excel dashboard and data visualisation

## Project Files

1. ShopSmart_Analysis.xlsx — Contains the retail analysis workbook, including calculations, PivotTables, charts, and the dashboard.

2. Executive_Dashboard.pdf — Presents the executive dashboard and key business performance indicators.

3. Business_Report.pdf — Documents data understanding, data cleaning, business questions and findings, and business recommendations.

4. README.md — Provides an overview of the project and its submitted files.

## Key Areas of Analysis

- Product and category revenue
- Store and regional sales performance
- Monthly sales trends
- Customer spending
- Product returns
- Inventory levels
- Business risks and growth opportunities

## Key Findings

The Beauty category generated the highest revenue among product categories analysed. ShopSmart Lagos recorded the highest store sales, while the East region recorded the highest regional sales. The analysis also identified inventory monitoring and data quality as areas requiring management attention.

## Business Recommendations

Recommendations include investing strategically in high-performing product categories, learning from successful stores and regions, improving inventory management, and strengthening supplier and product-return records.

## Conclusion

This project demonstrates how Microsoft Excel can be used to analyse retail data, visualise business performance, identify issues, and develop data-driven recommendations for ShopSmart Retail Ltd.
